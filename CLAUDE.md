# rondo-demos

Statički HTML demo sajtovi po delatnosti — prikazuju potencijalnim klijentima kako bi izgledao njihov sajt.

## Sadržaj

Srpski, ekavica, VI-forma. Nikad hrvatske reči (ovjes, tisuća, tjedan, rajčica, krumpir, tjestenina, žlica...).

## Struktura

Svaki demo je u `/{slug}/index.html` (self-contained, bez eksternih zavisnosti).

## Dodavanje novih demoa

Novi demo dodati u root `index.html` (meta description + hero broj + kartice). Uzeti bilo koji postojeći fajl kao template — ne menjati strukturu ni CSS varijable.
